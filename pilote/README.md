# pilote — spécification du WebUI grappes

**Commence par [`00-MAIN.md`](00-MAIN.md).** Il dit quoi faire, dans quel ordre, et ce qui n'est pas
négociable.

Les autres documents sont une chose à implémenter chacun, numérotés dans l'ordre de travail. `charte/`
contient les jetons de style, le vocabulaire et les composants ; `maquettes/` les trois pages
interactives du pilote. `source.md` est un briefing séparé (Aleph/FollowTheMoney/Maltego) fourni par
Sednal. `15-mecanismes-et-references.md` recense les mécanismes existants à reprendre.

**À partir du 26/10/2026, ce dossier ne s'enrichit plus que de texte** (`.md`) : les maquettes et les
aperçus de composants déjà présents restent comme référence visuelle, mais momo est seul à écrire et
faire évoluer le code et les visuels du pilote.

État au 26/10/2026.
